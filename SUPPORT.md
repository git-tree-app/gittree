# Getting help with GitTree

| You need | Go to |
|---|---|
| How to do something | The [documentation](https://gittree.app/en/docs), then [Discussions › Q&A](https://github.com/git-tree-app/gittree/discussions/categories/q-a) |
| Something is broken | The [bug report form](https://github.com/git-tree-app/gittree/issues/new?template=bug_report.yml), or **Report a Bug** in the app for a private support ticket |
| GitTree crashed | **Crash Reports…** in the command palette, then the [crash report form](https://github.com/git-tree-app/gittree/issues/new?template=crash_report.yml) |
| Account, plan, billing or refund | A [support ticket](https://gittree.app/en/support), or [info@gittree.app](mailto:info@gittree.app) |
| A security problem | Privately, as [SECURITY.md](SECURITY.md) describes |

Issues and discussions are public: keep tokens, passwords, invoices and private repository details for a support ticket.
