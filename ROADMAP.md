# Roadmap

What we are considering for GitTree. Nothing here is a promise or a date; the [release notes](https://github.com/git-tree-app/gittree/releases) say what has shipped. Vote in [Discussions › Ideas](https://github.com/git-tree-app/gittree/discussions/categories/ideas) to move something up.

## Getting GitTree

| Item | Status |
|---|---|
| Install and update on Ubuntu and Debian through `apt` (a signed package repository) | Under consideration |
| Snap Store | Applied; not available yet |
| Linux `.rpm` (Fedora, openSUSE) | Not started; tell us in Ideas if you need it |
| Linux arm64 | Not started; tell us in Ideas if you need it |
| Flatpak | Not planned for now: its sandbox cannot run your own `git`, `ssh` and hooks the way a Git client must |
