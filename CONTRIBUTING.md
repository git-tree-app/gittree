# Contributing to GitTree

GitTree is made by [Kodmora](https://kodmora.com). The app's source code is not public (see [Legal](README.md#legal)), but this repository is where GitTree's users meet, and there is a lot you can do here.

## Report a bug

Use the [bug report form](https://github.com/git-tree-app/gittree/issues/new?template=bug_report.yml). Your GitTree version is at the bottom right of the window; `git --version` gives Git's. A good report has the steps, what you expected and what happened.

Issues are public: leave out tokens, passwords, private repository names and company code. For anything private (your account, a payment, a problem you can't describe without private details) choose **Report a Bug** in the app instead: it opens a support ticket on gittree.app that only GitTree's team reads.

If GitTree crashed, open **Crash Reports…** from the command palette, read the saved report and post it with the [crash report form](https://github.com/git-tree-app/gittree/issues/new?template=crash_report.yml). Nothing is sent from the app.

## Suggest a feature or vote

Small, specific requests: the [feature request form](https://github.com/git-tree-app/gittree/issues/new?template=feature_request.yml). Bigger ideas: [Discussions › Ideas](https://github.com/git-tree-app/gittree/discussions/categories/ideas). A 👍 on an existing idea is the most useful thing you can do: the most-voted ideas are reviewed for every release.

## Help other people

Answer questions in [Discussions › Q&A](https://github.com/git-tree-app/gittree/discussions/categories/q-a) and share how you work in [Show and tell](https://github.com/git-tree-app/gittree/discussions/categories/show-and-tell).

## Improve the guides

Found a step in the [documentation](https://gittree.app/en/docs) or this README that is wrong or unclear? Open an issue with the page's address and what should change, or a pull request that edits this repository's Markdown.

Pull requests here change documentation and community files only; the installers in the releases are built from the private source.
