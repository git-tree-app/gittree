# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues or discussions. Report them privately through [**Security → Report a vulnerability**](https://github.com/git-tree-app/gittree/security/advisories/new), or e-mail [info@gittree.app](mailto:info@gittree.app) with "Security" in the subject.

Include the GitTree version (bottom right of the window), your operating system, what an attacker could do and how to reproduce it. We will acknowledge the report, keep you informed while we fix it, and credit you in the release notes if you wish.

## Supported versions

Fixes go into the latest release. GitTree offers updates itself; you can also download the newest version from [gittree.app](https://gittree.app) or the [Releases page](https://github.com/git-tree-app/gittree/releases/latest).

## Verifying downloads

Every release lists the SHA-256 of each installer in `SHA256SUMS.txt`; see [Verify your download](README.md#verify-your-download-optional).
